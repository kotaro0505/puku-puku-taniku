# Audio replacement slots

Place Godot-compatible audio files in this directory and set their `res://` paths in `data/audio-config.json`.

- BGM: `greenhouse`, `habitat`, `shop`
- SE: `ui_tap`, `watering`, `sprout`, `harvest`, `jelly`, `squish`, `level_up`, `new_species`, `seed_bag`, `purchase`, `payment`, `rare_seed`, `daily`, `result`, `result_new_best`

Empty paths are intentionally treated as silence and never cause a game error.
